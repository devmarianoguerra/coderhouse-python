# Sistema de administación de blog

Este sistema administra posts de un blog usando Python

## Inicio

Para iniciar el sistema hay que ubicarse en la carpeta de blog_consola y ejecutar python3 main.py

## Organización de carpetas

Las carpetas están organizadas de la siguiente manera

blog_consola/
│
├── main.py
├── README.md
│
└── blog/
├── **init**.py
├── datos.py
├── menu.py
├── operaciones.py
└── validaciones.py

## Modulos

- Main
  Encargado de ejecutar el programa

- blog/datos
  Encargado de administrar los datos del blog

- blog/menu
  Encargado de la lógica principal del menu

- blog/operaciones
  Contiene las funciones del menu

- blog/validaciones
  Contiene las validaciones del menu
